グレイコードによる将棋の長周期手順デモ

20ビットの循環グレイコードを用い、先手玉を最下位ビット、後手の19枚を残り19ビットに対応させています。 各ビットは 0/1 に応じて対応する駒が1歩だけ前後し、各手では1枚だけが動きます。

後手持駒：なし
先手持駒：残りすべて

操作

transition: 520ms
ply: 0

状態

手数: 0
反転ビット: -
局面ビット列: 00000000000000000000

直近のグレイコード遷移

対応

  • bit 0: 先手玉
  • bit 1〜19: 後手駒19枚
  • bit = 0: 図の位置
  • bit = 1: そこから1歩前進した位置
